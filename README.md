## 🌟 Overview

This portfolio is an ultra-futuristic, interactive 3D spatial experience. Instead of traditional up-and-down (Y-axis) scrolling, **this portfolio travels along the Z-axis (into the screen)**! As you scroll or swipe, the camera dives through futuristic quantum dimension gates, plunging into the screen to reveal project details, interactive labs, and dossiers with cinematic motion graphics.
